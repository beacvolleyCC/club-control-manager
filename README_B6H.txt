Club Control Manager V0.5.2B6H

Frontend-only patch on B6G.
- Mass training detail ordering: attendance summary -> time/court -> actions -> roster filters.
- Roster default surname A-Z / optional Z-A.
- Filter pass records: all / needs check / valid / missing.
- Pass badge shows canonical/imported valid month where available.
- Invalid, month-mismatch, missing/unmatched or waiting-check pass state is red.
- Expanded player cards, roster filters and scroll position survive note/pass-status saves.
- No config.js. No SQL required.
